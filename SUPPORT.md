# Support

How to get help with the Arbiter Project, by category.

## Questions

For general questions about Arbiter — usage, integration, conceptual queries — please open a [GitHub Discussion](../../discussions) if Discussions are enabled for the repository, or open an [Issue](../../issues) with the question.

Arbiter is at Alpha stage; response times may vary. Issues are reviewed regularly but turnaround depends on project priority and maintainer availability.

## Bugs

To report a bug or unexpected behavior:

- Open an [Issue](../../issues) titled as a bug report.
- Provide reproduction steps, expected vs. actual behavior, and environment details.
- For unclear issues, open a Discussion first to clarify.

## Feature requests

To suggest a feature or capability:

- Open an [Issue](../../issues) describing the capability and the problem it solves.
- See [ROADMAP.md](ROADMAP.md) for current and planned scope before requesting.

## Documentation improvements

To report missing, outdated, or incorrect documentation:

- Open an [Issue](../../issues) naming the file and what is wrong or missing.

## Security vulnerabilities

For security disclosures, use the private channel described in [SECURITY.md](SECURITY.md). Do not open public issues for security-impacting findings.

## Adversarial findings about the demo

To report classifier bypasses, content-moderation gaps, or other adversarial observations against the public demo, open an [Issue](../../issues) and say so in the title. These are welcomed as public research input.

## Trademark / name use

Questions about using the "Arbiter" name or branding should refer to [TRADEMARK.md](TRADEMARK.md). For permission requests not covered by the trademark policy, open an issue or contact the project via the SECURITY.md private channel.
