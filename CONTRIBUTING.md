# Contributing to Arbiter

Arbiter is in active Alpha through mid-2026. The codebase is not yet open to outside pull requests — the API surface and internal substrate continue to evolve, and we maintain coherent design control through the closed-loop Alpha.

## What we welcome now

- **Adversarial findings**: content-moderation bypasses, prompt-injection vectors, rate-limiter or blocklist gaps. File via [Issues](../../issues), saying in the title that it is an adversarial finding.
- **Use-case feedback**: tell us what domain problems Arbiter should handle.
- **Bug reports**: any deployment or runtime surface you've used.

## What we don't accept yet

- Pull requests against the core substrate, the LLM-serving proxy, or content-moderation rules.
- Documentation patches (docs flow from internal sources).

## Post-General-Availability

The contribution model expands once Arbiter reaches General Availability (target second half of 2026). Design RFCs and bug-fix PRs will both be in scope at that point.
